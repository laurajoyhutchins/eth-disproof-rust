# Redistribution license decision

**Owner decision required.** This repository currently has no license grant
for redistribution or derivative works. The fact that a repository or archive
is accessible does not by itself grant reuse rights.

If external collaboration or adoption is intended, choose and approve a license
(for example, MIT or Apache-2.0) and verify that all included third-party code,
reference implementations, and generated materials may be redistributed under
its terms. Only then add the approved full `LICENSE` text and appropriate
packaging metadata. No license has been selected on the owner's behalf.
