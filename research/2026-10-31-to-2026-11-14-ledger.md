## Decisions worth preserving

- **No “two implementations” maintenance trap.** Reconcile supported features into one canonical Lean in-process compiler and one runtime rather than layering incompatible JSON exporters, duplicate Nat types or feature-specific code generators.
- **No hidden exponential fallback.** The original small-input branch uses a noncomputably selected finite table. Arbitrary runtime enumeration changes the program and must not be called faithful compilation.
- **No optimism by stage count.** The limiting acceptance is one exact original nonterminal program through the full count path, independently checked on both sides; not hundreds of isolated passing tests.
- **No claim that an efficient spectral projector solves the count.** Low rank, sparse support, integer measurement constructibility, coefficient precision, interpolation condition and final reconstruction all matter simultaneously.
- **Avoid GitHub Actions as proof by itself.** A cached artifact is reusable only under source/ABI/toolchain identity; exact-head checks and independent original Lean executions distinguish reproducing a program from trusting a serialized fixture.
